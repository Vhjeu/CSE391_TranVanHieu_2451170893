# 📋 PHIẾU BÀI TẬP 09: DOM MANIPULATION & EVENTS

Repository này chứa mã nguồn của các mini-app thực hành thao tác với DOM (Document Object Model) và xử lý sự kiện (Events) sử dụng 100% Vanilla JavaScript (không dùng thư viện hay framework).

## 📂 Cấu Trúc Thư Mục

Dự án được chia thành 4 thư mục ứng với 4 bài tập thực hành:

* **`todo_app/`**: Ứng dụng quản lý công việc (Todo App) hoàn chỉnh. Tích hợp tính năng thêm/sửa/xóa, đánh dấu hoàn thành, lọc trạng thái, bộ đếm, Event Delegation và lưu trữ dữ liệu vĩnh viễn với LocalStorage.
* **`product_catalog/`**: Trang danh sách sản phẩm tương tác cao. Toàn bộ giao diện được render bằng JavaScript. Hỗ trợ tìm kiếm realtime, lọc theo danh mục, sắp xếp, Dark Mode và Modal chi tiết sản phẩm.
* **`form_validator/`**: Hệ thống kiểm tra tính hợp lệ của form (Form Validator) theo thời gian thực. Cung cấp phản hồi thị giác ngay khi người dùng gõ (độ mạnh mật khẩu, định dạng email, tự động format số điện thoại).
* **`keyboard_app/`**: Ứng dụng tối ưu hóa trải nghiệm điều hướng bằng bàn phím (Keyboard Shortcuts) và Accessibility. Bao gồm thao tác chuyển ảnh bằng phím mũi tên, Command Palette (Ctrl+K) và quản lý Focus.
