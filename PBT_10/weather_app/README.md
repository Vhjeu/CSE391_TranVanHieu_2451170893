# ⛅ Weather App

Ứng dụng xem thời tiết hiện tại của một thành phố với các trạng thái xử lý bất đồng bộ (Loading, Success, Error) và lưu trữ lịch sử tìm kiếm.

## 🔌 API Sử Dụng

* **wttr.in API**: `https://wttr.in/{city}?format=j1`
* Cung cấp dữ liệu thời tiết theo thời gian thực dựa trên tên khu vực.

## 🚀 Cách Chạy Ứng Dụng

1. Mở thư mục `weather_app`.
2. Chạy file `index.html` trực tiếp trên trình duyệt (Chrome, Edge, Firefox,...) hoặc sử dụng extension **Live Server** trên VS Code.
3. Nhập tên thành phố (ví dụ: Hanoi) vào ô tìm kiếm và nhấn "Tìm".
4. *Lưu ý:* Cần có kết nối Internet để gọi API tải dữ liệu thời tiết.
