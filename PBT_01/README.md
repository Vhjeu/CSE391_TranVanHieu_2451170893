# 📋 PHIẾU BÀI TẬP 01: HTML5 FUNDAMENTALS

Repository này chứa bài tập thực hành về các nền tảng cốt lõi của HTML5, tập trung vào việc xây dựng cấu trúc trang web chuẩn Semantic, sử dụng Table, Links và làm quen với công cụ DevTools trên trình duyệt.

## 📂 Cấu Trúc Thư Mục & File

Dự án bao gồm các file sau để giải quyết từng phần của phiếu bài tập:

* **`answers.md`**: File Markdown chứa toàn bộ câu trả lời lý thuyết (Phần A), các bước phân tích trang web thật, và phần suy luận/tranh luận về Semantic HTML (Phần C).
* **`profile.html`**: Trang giới thiệu bản thân áp dụng triệt để các thẻ Semantic HTML5 (`<header>`, `<main>`, `<article>`, `<section>`, `<footer>`...) và Bảng (`<table>`). Hoàn toàn không lạm dụng thẻ `<div>`.
* **`products.html`**: Trang danh sách sản phẩm E-Commerce mẫu. Kết hợp hiển thị thẻ sản phẩm dạng lưới cơ bản và bảng so sánh thông số kỹ thuật sử dụng `colspan`/`rowspan`.
* **`debug.html`**: Chứa mã nguồn HTML đã được sửa và dọn dẹp sạch sẽ từ đoạn code chứa nhiều lỗi syntax và semantic trong đề bài.
* **`screenshots/`**: Thư mục chứa các ảnh chụp màn hình tab Network, Elements từ DevTools để minh họa cho phần lý thuyết và phân tích web.

## 🚀 Hướng Dẫn Xem Dự Án

Vì đây là các file HTML cơ bản chưa có CSS và JavaScript phức tạp, bạn có thể xem trực tiếp rất dễ dàng:

1. Clone repository này về máy tính của bạn.
2. Mở thư mục chứa dự án.
3. Nhấp đúp chuột vào các file `profile.html`, `products.html` hoặc `debug.html` để mở trực tiếp trên trình duyệt web (Chrome, Edge, Firefox...).
4. Để đọc file `answers.md`, bạn có thể mở bằng Visual Studio Code (nhấn `Ctrl + Shift + V` để xem preview) hoặc xem trực tiếp trên giao diện của GitHub.

## 🛠️ Kiến Thức Trọng Tâm Đạt Được

* **Hiểu luồng HTTP/Browser:** Nắm được quá trình từ khi gõ URL đến khi trang web được render và biết cách đọc các thông số cơ bản trong tab Network của DevTools.
* **Tư duy Semantic HTML5:** Biết cách chọn đúng thẻ cho đúng mục đích (VD: dùng `<figure>` cho ảnh, `<article>` cho sản phẩm, `<nav>` cho điều hướng) để tối ưu hóa SEO và Accessibility.
* **Cấu trúc Bảng (Tables):** Sử dụng chuẩn xác các thành phần `<thead>`, `<tbody>`, `<tfoot>` và gộp ô. 
* **Debug HTML:** Nhận diện và sửa các lỗi cú pháp mồ côi thẻ, lồng thẻ sai quy tắc.
